# Hinter Hind

Подсказчик для технических собеседований на macOS. Слушает звонок, распознаёт вопрос собеседника и за пару секунд показывает короткие тезисы ответа с учётом вашего резюме и вакансии. Окно-подсказка полупрозрачное и не попадает в демонстрацию экрана.

*A macOS interview copilot: listens to the call, detects the interviewer's question and shows short answer bullets based on your resume and the job description. The overlay is excluded from screen sharing. Docs are in Russian.*

---

## Возможности

- **Подсказки по голосу.** Собеседник задал вопрос и замолчал — через 2–3 секунды на панели появляются 3–5 коротких тезисов. Нажимать ничего не нужно.
- **Задачи с экрана.** ⌃⌥S — снимок экрана (без самой панели) уходит в модель, в ответ — код решения и пара строк объяснения. Подходит для задач в чате звонка, CoderPad, LeetCode.
- **Ваш контекст.** Подсказки опираются на ваше резюме и текст вакансии (PDF, txt или md). Перед конкретным звонком их можно подменить.
- **Невидимость в демонстрации.** Окно исключено из захвата экрана средствами macOS: не видно ни при показе всего экрана, ни в списке окон для показа. Проверено в Zoom и Google Meet.
- **Русский и английский.** Голос собеседника распознаёт локальный Whisper: английские термины в русской речи (OOMKilled, CrashLoopBackOff, Kubernetes) пишутся правильно.
- **Три провайдера на выбор:** NVIDIA NIM (быстрее всего, по API-ключу), Claude Code и Codex (через ваши подписки). Переключение на лету — ⌃⌥P.
- **Приватность.** Звук распознаётся только на вашем Mac и никуда не отправляется. Расшифровки звонков хранятся локально в зашифрованном виде.

## Как это работает

```
звук собеседника ─► Whisper (локально) ─► определение вопроса ─┐
ваш микрофон ───► распознавание Apple (локально) ─► контекст ──┼─► модель (NIM / Claude / Codex) ─► панель
резюме + вакансия ─────────────────────────────────────────────┘
⌃⌥S ─► снимок экрана ─► модель ─► код решения
```

- Звук собеседника — это системный звук Mac (то, что вы слышите из звонка). Ваш голос — микрофон. Поэтому приложение различает, кто говорит.
- Подсказка запускается, когда собеседник закончил фразу, похожую на вопрос. На реплики вроде «вы меня слышите?» модель отвечает «—», и панель не меняется.

## Требования

- **Mac на Apple Silicon** (M1 и новее), **macOS 26** или новее.
- **Xcode 26** (бесплатно из App Store) — для сборки. Одних Command Line Tools не хватит.
- **Homebrew** — https://brew.sh
- ~1 ГБ на диске под модель распознавания речи, ~700 МБ оперативной памяти во время звонка.
- Хотя бы один провайдер ответов (см. «Подключение провайдеров»).

## Установка

### 1. Скачайте код

```bash
git clone https://github.com/<аккаунт>/hinter-hind.git
cd hinter-hind
```

### 2. Установите whisper.cpp и модель распознавания

```bash
brew install whisper-cpp
```

```bash
mkdir -p ~/Library/Application\ Support/HinterHind/models
curl -L -o ~/Library/Application\ Support/HinterHind/models/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
```

Модель весит 574 МБ и скачивается из официального репозитория whisper.cpp. Без неё приложение работает на встроенном распознавателе Apple, но английские термины в русской речи он искажает.

### 3. Создайте сертификат для подписи (один раз, ~2 минуты)

Без него macOS будет заново спрашивать все разрешения после каждой пересборки.

1. Откройте «Связку ключей»: `open "/System/Library/CoreServices/Applications/Keychain Access.app"`
2. Слева выберите связку **«Вход»** (не iCloud).
3. В строке меню: «Связка ключей» → «Ассистент сертификации» → «Создать сертификат…».
4. Имя: **`HinterHind`** (ровно так), тип личности: «Самоподписанный корневой», тип сертификата: «Подпись кода». Нажмите «Создать».

Сертификат работает только на вашем Mac и никуда не публикуется.

### 4. Соберите и запустите

```bash
./scripts/bundle.sh
```

```bash
open build/HinterHind.app
```

При первой сборке macOS спросит доступ к ключу сертификата — нажмите «Разрешить всегда». Если сертификата нет, скрипт подпишет приложение без него и предупредит об этом.

Приложение живёт в строке меню (значок 💬), в Dock его нет.

### 5. Выдайте разрешения

При запуске приложение само проверяет готовность и запрашивает всё нужное:

| Разрешение | Зачем |
|---|---|
| Микрофон | распознавать ваши реплики |
| Запись экрана и системного звука | слышать собеседника и делать снимок задачи по ⌃⌥S |
| Распознавание речи | ваши реплики (распознаватель Apple) |
| Доступ к связке ключей | хранить ключ NIM и ключ шифрования расшифровок |

После выдачи «Записи экрана» **перезапустите приложение** — macOS применяет это разрешение только к новому процессу. Когда всё готово, на панели появится «✓ Готово к звонку». Повторить проверку: меню 💬 → «Проверить готовность».

## Подключение провайдеров

Достаточно одного. Переключение — ⌃⌥P или меню 💬 → «Провайдер».

### NVIDIA NIM — рекомендуется (быстрее всего, ~0,5 с до первого слова)

1. Зарегистрируйтесь на https://build.nvidia.com и создайте API-ключ (начинается с `nvapi-`).
2. Сохраните ключ в текстовый файл (txt или rtf) — **вне папки проекта**.
3. Меню 💬 → «Импорт ключа NIM из файла…» → выберите файл.
4. Ключ сохранится в связке ключей macOS; файл после этого можно удалить.

Используются модели `nvidia/nemotron-3.5-super-vl-120b-a12b` (текст и скриншоты). Бесплатный тариф NIM иногда отвечает медленно или с ошибкой — тогда переключитесь на другого провайдера.

### Claude Code (по подписке Claude)

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

```bash
claude
```

Войдите в аккаунт в открывшемся интерфейсе. Приложение вызывает `claude -p` и найдёт его в `~/.local/bin`, `/opt/homebrew/bin` или `/usr/local/bin`. Каждый запрос стартует 1–3 секунды — медленнее NIM.

### Codex (по подписке ChatGPT)

```bash
npm install -g @openai/codex
```

```bash
codex
```

Войдите в аккаунт. Приложение вызывает `codex exec`. Как и Claude, стартует 1–3 секунды на запрос.

## Перед собеседованием

1. **Загрузите резюме и вакансию:** меню 💬 → «Резюме по умолчанию…» и «Вакансия по умолчанию…» (PDF, txt, md). Это главный рычаг качества: без них ответы общие, а на вопросы о себе модель начинает выдумывать.
   - Совет: допишите в резюме 3–5 своих историй в формате STAR (ситуация, задача, что сделали лично вы, результат с цифрами). Тогда на поведенческие вопросы будут подсказки по **вашему** опыту.
2. **Для конкретного звонка** можно подменить файлы: «Резюме для этого звонка…», «Вакансия для этого звонка…» — после звонка вернутся файлы по умолчанию.
3. **Поставьте панель прямо под камерой** (центр верхнего края экрана) — так при чтении меньше заметно, что взгляд уходит в сторону. Подберите размер шрифта: меню 💬 → «Размер шрифта».
4. **Наденьте наушники.** Без них микрофон слышит собеседника из динамиков; приложение это эхо отфильтровывает, но с наушниками надёжнее.
5. **Проверьте невидимость** в своей платформе звонков: начните демонстрацию экрана и посмотрите со второго устройства.
6. Меню 💬 → «Начать звонок».

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌃⌥A | ответить на последний вопрос сейчас (не дожидаясь паузы) |
| ⌃⌥S | снимок экрана → решение задачи |
| ⌃⌥P | следующий провайдер (NIM → Claude → Codex) |
| ⌃⌥L | язык распознавания: русский ⇄ английский |
| ⌃⌥H | скрыть / показать панель |
| ⌃⌥C | клики проходят сквозь панель |
| ⌃⌥↑ / ⌃⌥↓ | прокрутить ответ |

Длинные ответы прокручиваются сами: пауза наверху, шаги вниз, пауза внизу, возврат наверх.

## Меню 💬

- **Начать / Остановить звонок**, **Проверить готовность**
- **Провайдер**, **Язык**, **Прозрачность**, **Размер шрифта**
- **Резюме / Вакансия** — по умолчанию и для этого звонка
- **Импорт ключа NIM из файла…**
- **Экспорт расшифровки…** — расшифровывает запись звонка в текстовый файл для разбора
- **Выход**

Размер и положение панели меняются мышью и запоминаются; высота подстраивается под текст, а заданная вами высота становится максимумом.

## Приватность и безопасность

- **Звук** не записывается на диск и не покидает Mac: голос собеседника распознаёт локальный Whisper (`whisper-server` слушает только `127.0.0.1`), ваш — встроенный распознаватель Apple.
- **Что уходит провайдеру:** текст последних ~2 минут разговора, резюме, вакансия и (по ⌃⌥S) снимок экрана. Без этого ответ не сгенерировать. Учитывайте политику конфиденциальности выбранного провайдера.
- **Расшифровки** звонков сохраняются в `~/Library/Application Support/HinterHind/sessions/`, каждая строка зашифрована AES-GCM, ключ — в связке ключей macOS. Прочитать — меню 💬 → «Экспорт расшифровки…». Удалить — просто удалите файлы.
- **Ключ NIM** хранится только в связке ключей. Никогда не кладите файл с ключом в папку проекта и не коммитьте его (`.gitignore` закрывает `*.rtf`, `*key*.txt`, `nim_api_key*`).

## Известные ограничения

- **Только macOS на Apple Silicon.** Windows и Linux не поддерживаются.
- **Невидимость** обеспечивает системная функция macOS (`NSWindow.sharingType = .none`). В Zoom и Google Meet проверена, в Microsoft Teams — нет. Apple может изменить её поведение в обновлениях — проверяйте перед важным звонком.
- **Курсор мыши** в демонстрации виден. Не водите им над панелью; прокрутка — клавишами.
- **Качество распознавания** зависит от звука собеседника: при тихом или шумном звуке Whisper ошибается, а иногда выдаёт фразы-галлюцинации (часть из них отфильтровывается).
- **Модель может ошибаться и выдумывать**, особенно в вопросах о вашем опыте без загруженного резюме. Не зачитывайте то, что не можете объяснить.
- **Нагрев.** Whisper использует GPU на каждую фразу собеседника; на MacBook Air во время долгого звонка корпус заметно теплеет.

## Решение проблем

| Проблема | Что сделать |
|---|---|
| Разрешения запрашиваются после каждой сборки | создайте сертификат `HinterHind` (шаг 3 установки) и пересоберите |
| Панели не видно | ⌃⌥H; если не помогло — `defaults delete com.hinterhind.app panelFrame` и перезапуск |
| Нет подсказок на вопросы | смотрите расшифровку (меню → «Экспорт расшифровки…»): там видно «вопрос обнаружен», «модель пропустила (—)» или ошибку |
| «Whisper недоступен» | `brew install whisper-cpp` и проверьте, что модель лежит в `~/Library/Application Support/HinterHind/models/` |
| «claude/codex не установлен» | установите CLI (см. «Подключение провайдеров») или переключитесь ⌃⌥P |
| Ответ «Not logged in» от Claude | запустите `claude` в терминале и войдите |

## Разработка

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
```

- `Sources/HinterCore` — логика без UI (промпты, провайдеры, определение вопроса, нарезка речи, шифрование) — покрыта тестами.
- `Sources/HinterHind` — приложение: панель, захват звука и экрана, меню, горячие клавиши.
- Тесты с реальными провайдерами запускаются только явно: `HH_LIVE=1`.

## Ответственность

Это инструмент для подготовки и тренировки: прогоняйте пробные собеседования, разбирайте свои ответы по расшифровкам, учитесь формулировать. Многие компании прямо запрещают сторонние подсказки на интервью, и их обнаружение обычно означает отказ или увольнение. Решение, как использовать инструмент, и ответственность за него — на вас.
